Proposal 1 — deletion drains in red

Birth fills green (hollow → half → solid); death drains red (solid → half → hollow). A deleting chunk's pips flip to the red hue: still-holding nodes pulse solid, mid-purge shows half-drained, an acked node leaves a dim hollow ring. The laggard blocking the receipt protocol is the one still burning red. Row disappears entirely on finalize.

Proposal 2 — stale residency: the ghost pip

A node outside placement reporting a copy renders as an extra muted dot, set off by a gap: the anomaly is literally a dot that should not exist. Tooltip names the node and says "stale residency — copy present, node not in placement".

Proposal 3 — cloud-backed chunks: the blob mark

Per-home pips are the wrong story once bytes live in a blob store. Cloud-backed chunks swap the pip row for a single blob mark; dashed + pulsing while the upload runs. If a local cache copy exists it can render as one calm pip beside the mark (shown in row 3) — or we drop that and keep the mark alone.
